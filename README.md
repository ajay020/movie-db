## Movie Database

A responsive movie database application built with React, TypeScript, and the TMDB API. Users can discover movies, search for titles, browse movies by genre, view detailed movie information, watch trailers, and save their favorite movies.

## Features

- Browse popular, now playing, and top-rated movies
- Search movies with debounced search
- Browse movies by genre with pagination
- View movie details, cast, similar movies, and trailers
- Add and remove movies from favorites
- Persist favorites using localStorage
- Responsive UI with Tailwind CSS
- Loading, error, and empty states

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- Zustand
- React Router
- Axios
- TMDB API
